セールス クローザー ダッシュボード｜セットアップ

このページは「くみこ用」の作業メモです。3ステップで稼働します。クローザーの実名・メール・目標などの個人情報は、この公開ページには載せていません（別途お渡しする「SEED」で投入します）。

1Supabase にテーブルを作る

  1. Supabase プロジェクト（ナーチャリング共有ボード等と同じもの）を開く
  2. 左メニュー SQL Editor → New query
  3. 同フォルダの schema.sql の中身を 全部貼って RUN（テーブル＋アクセス制御が作られます／既存テーブルには触れません）
  4. 続けて、くみこに個別にお渡しした SEED（非公開） を貼って RUN（名簿・メール・今月の目標が入ります）

SEED を入れ替えるだけで、クローザーの追加・削除・目標変更ができます。

2ログイン用リンクの許可設定（Auth）

  1. Supabase → Authentication → URL Configuration
  2. Site URL と Redirect URLs に、このダッシュボードの公開URL（GitHub Pages のURL）を追加
  3. これで、許可メールの人が「ログイン用リンク」を受け取れます（パスワード不要）

3Slack 自動投稿をつなぐ（任意・あとからでOK）

  1. Slack で Incoming Webhook を作成し、投稿先に #マーケ03_セールス報告スレ を選ぶ
  2. 同フォルダの slack-bot.gs を新規 Apps Script に貼り、スクリプトプロパティに SLACK_WEBHOOK_URL を登録
  3. ウェブアプリとしてデプロイ → 出てきた /exec URL を supabase_config.js の slackRelayUrl に貼る
  4. testPost() を実行して #マーケ03 に届けば完了

Slack Webhook（秘密情報）は GAS の中だけに保管され、公開リポジトリにもダッシュボードにも出ません。未設定でもダッシュボードは通常どおり動きます（Slack投稿だけスキップ）。

使い方

  • 各クローザーは自分の会社メールでログイン → 自分の名前のタブで「本日の報告」を入力して送信
  • 送信すると ①集計ダッシュボードに即反映 ＋ ②マーケ03へ自動投稿（＝二重入力が不要に）
  • 一番左の 「集計（チーム）」タブで、月間目標／成約数／達成率／口頭合意の追客状況をひと目で確認
  • 自分のタブを直接開くリンク：?me=スラッグ（例 ?me=honda）
