# セールス クローザー ダッシュボード

クローザーの日次報告を **1回の入力**で「ダッシュボード反映」＋「Slack（マーケ03）自動投稿」まで完結させ、
シートとSlackへの二重入力をなくすための社内ツール。

- 一番左＝**集計（チーム）**タブ、その右に**クローザー別タブ**（面談ダッシュボードと同じ構成）
- 月間成約目標／成約数／達成率／面談・即決・成約率／口頭合意の追客状況を可視化
- データは Supabase（RLS・許可メール限定）。ページ自体に個人情報・数値は含まれません

## 構成
| ファイル | 役割 |
|---|---|
| `index.html` | ダッシュボード本体（集計＋クローザー別タブ＋入力フォーム） |
| `supabase_config.js` | Supabase接続＋Slack連携URL設定 |
| `schema.sql` | テーブル定義＋アクセス制御（PIIなし・公開OK） |
| `setup.html` | くみこ用セットアップ手順 |
| `slack-bot.gs` | フォーム→マーケ03自動投稿（GAS Web App、Webhookはサーバ側保管） |
| `SEED_PRIVATE.sql` | 名簿・メール・目標（**非公開／gitignore**。Supabaseに直接投入） |
